# Quantum Singularity

Quantum-/IONOS-Prototyp mit `backend/`, `core/`, `modules/`, Flask-Entrypoint, Templates und statischen Ressourcen.

## Bereinigung
Entfernt wurden nur eindeutig technische Altlasten (`.DS_Store`, leere `.env.py`, leere Platzhalterdatei). Vorhandener Quellcode und Design bleiben erhalten. Die verschachtelten Altprojekte werden in einem weiteren Schritt gegen `core/` und `backend/` auf Duplikate geprüft.
